## ⚡ Inicio Rápido (Quickstart)

1. Abre la terminal en esta carpeta:
   ```powershell
   cd PODA_360
   ```
2. Inicia el servidor Node.js nativo:
   ```powershell
   node server.js
   ```
3. Accede desde tu navegador:
   ```
   http://localhost:3000
   ```
4. Haz clic en **«Iniciar Demo Interactiva»** en la pantalla principal para explorar el mapa de La Dorada, el inspector del Samán Centenario, el simulador in vitro y la calculadora de enrutamiento.

## 📊 Métricas Clave de Impacto

* **`-11.4 °C`**: Atenuación térmica en la matriz edáfica radicular (de 38.8 °C a 27.4 °C).
* **`+49 %`**: Humedad conservada tras 7 días de sequía extrema sin riego suplementario.
* **`$115.000 COP/t`**: Costo de disposición evitado al desviar biomasa del Relleno Sanitario La Doradita.
* **`10 Nodos`**: Puntos reales auditados y georreferenciados en La Dorada, Caldas.
* **`0 Emojis`**: Interfaz 100% limpia con la librería nativa de 46 vectores SVG **Colombia Icons**.
